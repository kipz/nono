---
title: OAuth Credentials (MCP & Claude.ai)
description: Keep OAuth access tokens out of the sandbox — manage token refresh and browser login flows on the host, inject only via the proxy
---

Many services that AI agents talk to — MCP servers, and the Claude.ai API itself — use OAuth2 access tokens rather than static API keys. These tokens are short-lived (typically minutes to hours), backed by refresh tokens, and occasionally require a full browser re-authorisation flow. nono's `cmd://` capture mechanism, combined with `credential_capture` and `interaction.open_urls`, composes into a complete solution without ever letting the token enter the sandbox.

---

## How it works

```
Agent calls mcp.example.com
    ↓
Proxy intercepts (phantom token in Authorization header)
    ↓
No valid cached token? → Supervisor runs token-cache helper (cmd://)
    ↓
Helper: check keychain → still valid? emit access_token
                        → expired + refresh_token? call /token endpoint, update keychain, emit
                        → no refresh? open browser, complete PKCE flow, store to keychain, emit
    ↓
Proxy injects real Bearer token into upstream request
    ↓
Response streamed back to agent
```

The sandboxed agent never holds the real access token — it only ever sees the phantom session token. The helper and token cache live on the host, outside the sandbox.

---

## Writing a token-cache helper

The helper is a regular host-side script. nono calls it each time the cache is cold (controlled by `cache_ttl_secs`). It must:

1. Print the current access token to **stdout** and exit 0.
2. Silently refresh with the stored refresh token when the cached token is near expiry.
3. Fall back to an interactive browser flow if no refresh token is available.
4. Exit non-zero if it cannot produce a token (nono will surface a 503 to the agent and record an audit event).

Tokens are stored in the **system keychain** (macOS Keychain, Linux Secret Service) via the [`keyring`](https://pypi.org/project/keyring/) library — not on disk — so they are protected by the OS credential store.

Install the dependency once:

```bash
pip install keyring
```

### Generic Python skeleton

```python
#!/usr/bin/env python3
"""
Generic MCP OAuth token helper for nono.
Stores tokens in the system keychain via the `keyring` library.

Usage:
    mcp-token-helper <provider-name> <token-endpoint> <client-id>
"""
import json
import os
import sys
import time
import urllib.request
import urllib.parse

try:
    import keyring
except ImportError:
    print("mcp-token-helper: pip install keyring", file=sys.stderr)
    sys.exit(1)

KEYRING_SERVICE = "nono-mcp"
EXPIRY_BUFFER_MS = 60_000  # refresh 60 s before actual expiry


def load(key):
    raw = keyring.get_password(KEYRING_SERVICE, key)
    if raw:
        try:
            return json.loads(raw)
        except json.JSONDecodeError:
            pass
    return None


def store(key, token_data):
    keyring.set_password(KEYRING_SERVICE, key, json.dumps(token_data))


def do_refresh(token_endpoint, client_id, refresh_tok):
    payload = urllib.parse.urlencode({
        "grant_type": "refresh_token",
        "client_id": client_id,
        "refresh_token": refresh_tok,
    }).encode()
    req = urllib.request.Request(
        token_endpoint,
        data=payload,
        headers={"Content-Type": "application/x-www-form-urlencoded"},
        method="POST",
    )
    with urllib.request.urlopen(req, timeout=15) as resp:
        return json.loads(resp.read())


def main():
    if len(sys.argv) < 4:
        print(f"usage: {sys.argv[0]} <provider> <token-endpoint> <client-id>", file=sys.stderr)
        sys.exit(1)

    provider, token_endpoint, client_id = sys.argv[1], sys.argv[2], sys.argv[3]
    now_ms = int(time.time() * 1_000)
    token_data = load(provider)

    if token_data and token_data.get("expires_at_ms", 0) > now_ms + EXPIRY_BUFFER_MS:
        sys.stdout.write(token_data["access_token"])
        return

    if token_data and token_data.get("refresh_token"):
        try:
            body = do_refresh(token_endpoint, client_id, token_data["refresh_token"])
            if body.get("access_token"):
                new_data = {
                    "access_token": body["access_token"],
                    "refresh_token": body.get("refresh_token") or token_data["refresh_token"],
                    "expires_at_ms": now_ms + body.get("expires_in", 3600) * 1_000,
                }
                store(provider, new_data)
                sys.stdout.write(new_data["access_token"])
                return
        except Exception as exc:
            print(f"mcp-token-helper: refresh failed: {exc}", file=sys.stderr)

    if os.environ.get("NO_BROWSER_LOGIN") == "1":
        print(f"mcp-token-helper: no valid token for '{provider}' and NO_BROWSER_LOGIN=1", file=sys.stderr)
        sys.exit(1)

    # Provider-specific browser flow: complete PKCE auth, then call store().
    # See the Slack example below for a concrete implementation.
    print(f"mcp-token-helper: no valid token for '{provider}' — implement browser flow here", file=sys.stderr)
    sys.exit(1)


if __name__ == "__main__":
    main()
```

Place at a stable path and make it executable:

```bash
install -m 755 mcp-token-helper.py /usr/local/libexec/mcp-token-helper
```

## Pattern: MCP server OAuth tokens

Use this pattern for any remote MCP server that issues short-lived access tokens.

### Profile

```jsonc
{
  "extends": "default",
  "meta": { "name": "agent-with-mcp" },
  "network": {
    "custom_credentials": {
      "example_mcp": {
        "upstream": "https://mcp.example.com",
        "credential_key": "cmd://example_mcp",
        "env_var": "EXAMPLE_MCP_TOKEN",
        "inject_header": "Authorization",
        "credential_format": "Bearer {}",
        "endpoint_rules": [
          { "method": "*", "path": "/mcp" },
          { "method": "*", "path": "/mcp/**" }
        ]
      }
    },
    "credentials": ["example_mcp"]
  },
  "credential_capture": {
    "example_mcp": {
      "command": [
        "/usr/local/libexec/mcp-token-helper",
        "example_mcp",
        "https://auth.example.com/oauth/token",
        "<client-id>"
      ],
      "timeout_secs": 300,
      "cache_ttl_secs": 240,
      "interaction": {
        "open_urls": {
          "allow_origins": ["https://example.com", "https://auth.example.com"],
          "allow_localhost": true
        },
        "allow_launch_services": true
      }
    }
  }
}
```

**Key points:**

- `cache_ttl_secs: 240` is shorter than a typical 300-second token lifetime — the helper refreshes proactively before the proxy would call it again.
- `endpoint_rules` restricts injection to `/mcp` and `/mcp/**` — the token is not sent to other paths on the same upstream.
- `interaction.open_urls` allows the browser to open only the provider's auth domain and localhost (for PKCE redirect).
- Tokens live in the system keychain, not on disk, so no `filesystem.deny` entry is needed for the cache.

## Example: Slack MCP

[Slack's MCP server](https://mcp.slack.com) implements standard OAuth2 PKCE with the following endpoints (discovered from `https://mcp.slack.com/.well-known/oauth-authorization-server`):

| | |
|---|---|
| Authorization | `https://slack.com/oauth/v2_user/authorize` |
| Token / refresh | `https://slack.com/api/oauth.v2.user.access` |

Initial auth is handled by [`mcp-remote`](https://github.com/modelcontextprotocol/mcp-remote), which drives the PKCE browser flow. The helper migrates the resulting tokens into the system keychain and handles all subsequent refreshes itself without re-invoking mcp-remote.

### Prerequisites

```bash
pip install keyring
npm install -g mcp-remote   # or: npx mcp-remote (no install needed)
```

### Token helper

```python
#!/usr/bin/env python3
"""
Slack MCP token helper for nono.

First run: triggers browser auth via mcp-remote, then migrates tokens to keychain.
Subsequent runs: refreshes silently from keychain via Slack's token endpoint.
"""
import hashlib
import json
import os
import pathlib
import subprocess
import sys
import time
import urllib.request
import urllib.parse

try:
    import keyring
except ImportError:
    print("slack-mcp-token-helper: pip install keyring", file=sys.stderr)
    sys.exit(1)

MCP_URL = "https://mcp.slack.com/mcp"
TOKEN_ENDPOINT = "https://slack.com/api/oauth.v2.user.access"
KEYRING_SERVICE = "nono-mcp"
KEYRING_KEY = "slack_mcp"
EXPIRY_BUFFER_MS = 60_000


def load():
    raw = keyring.get_password(KEYRING_SERVICE, KEYRING_KEY)
    if raw:
        try:
            return json.loads(raw)
        except json.JSONDecodeError:
            pass
    return None


def store(token_data):
    keyring.set_password(KEYRING_SERVICE, KEYRING_KEY, json.dumps(token_data))


def do_refresh(refresh_tok):
    # Slack's token endpoint accepts refresh_token grant for MCP tokens.
    # The client_id was registered by mcp-remote's DCR flow and is stored in
    # the client_info file; for the public Slack MCP app it is fixed.
    payload = urllib.parse.urlencode({
        "grant_type": "refresh_token",
        "refresh_token": refresh_tok,
    }).encode()
    req = urllib.request.Request(
        TOKEN_ENDPOINT,
        data=payload,
        headers={"Content-Type": "application/x-www-form-urlencoded"},
        method="POST",
    )
    with urllib.request.urlopen(req, timeout=15) as resp:
        return json.loads(resp.read())


def find_mcp_remote_tokens():
    """
    mcp-remote stores tokens in ~/.mcp-auth/<version-dir>/<md5(url)>_tokens.json.
    Walk all version directories and return the first matching tokens file found.
    """
    url_hash = hashlib.md5(MCP_URL.encode()).hexdigest()
    mcp_auth = pathlib.Path.home() / ".mcp-auth"
    if not mcp_auth.is_dir():
        return None
    for version_dir in sorted(mcp_auth.iterdir(), reverse=True):  # newest version first
        candidate = version_dir / f"{url_hash}_tokens.json"
        if candidate.exists():
            try:
                return json.loads(candidate.read_text()), candidate
            except (json.JSONDecodeError, OSError):
                pass
    return None, None


def migrate_from_disk():
    """Read tokens from mcp-remote disk cache, store in keychain, delete from disk."""
    result = find_mcp_remote_tokens()
    if result[0] is None:
        return None
    disk_tokens, token_file = result
    # mcp-remote files have no expires_at; set to 0 to force an immediate refresh.
    token_data = {
        "access_token": disk_tokens["access_token"],
        "refresh_token": disk_tokens.get("refresh_token", ""),
        "expires_at_ms": 0,
    }
    store(token_data)
    try:
        token_file.unlink()  # remove from disk now that it is in keychain
    except OSError:
        pass
    return token_data


def browser_auth():
    if os.environ.get("NO_BROWSER_LOGIN") == "1":
        print("slack-mcp-token-helper: token expired and NO_BROWSER_LOGIN=1", file=sys.stderr)
        sys.exit(1)
    print("slack-mcp-token-helper: launching browser auth via mcp-remote", file=sys.stderr)
    try:
        subprocess.run(
            ["npx", "--yes", "mcp-remote", MCP_URL, "--once"],
            timeout=300,
        )
    except subprocess.TimeoutExpired:
        print("slack-mcp-token-helper: browser auth timed out", file=sys.stderr)
        sys.exit(1)
    return migrate_from_disk()


def main():
    now_ms = int(time.time() * 1_000)
    token_data = load()

    # Valid cached token
    if token_data and token_data.get("expires_at_ms", 0) > now_ms + EXPIRY_BUFFER_MS:
        sys.stdout.write(token_data["access_token"])
        return

    # Refresh
    if token_data and token_data.get("refresh_token"):
        try:
            body = do_refresh(token_data["refresh_token"])
            if body.get("ok") and body.get("access_token"):
                new_data = {
                    "access_token": body["access_token"],
                    "refresh_token": body.get("refresh_token") or token_data["refresh_token"],
                    "expires_at_ms": now_ms + body.get("expires_in", 3600) * 1_000,
                }
                store(new_data)
                sys.stdout.write(new_data["access_token"])
                return
        except Exception as exc:
            print(f"slack-mcp-token-helper: refresh failed: {exc}", file=sys.stderr)

    # Check disk cache left by mcp-remote (e.g. first run, or after mcp-remote upgraded)
    migrated = migrate_from_disk()
    if migrated and migrated.get("refresh_token"):
        try:
            body = do_refresh(migrated["refresh_token"])
            if body.get("ok") and body.get("access_token"):
                new_data = {
                    "access_token": body["access_token"],
                    "refresh_token": body.get("refresh_token") or migrated["refresh_token"],
                    "expires_at_ms": now_ms + body.get("expires_in", 3600) * 1_000,
                }
                store(new_data)
                sys.stdout.write(new_data["access_token"])
                return
        except Exception as exc:
            print(f"slack-mcp-token-helper: refresh after migration failed: {exc}", file=sys.stderr)

    # Full browser auth
    new_token = browser_auth()
    if new_token and new_token.get("refresh_token"):
        try:
            body = do_refresh(new_token["refresh_token"])
            if body.get("ok") and body.get("access_token"):
                new_data = {
                    "access_token": body["access_token"],
                    "refresh_token": body.get("refresh_token") or new_token["refresh_token"],
                    "expires_at_ms": now_ms + body.get("expires_in", 3600) * 1_000,
                }
                store(new_data)
                sys.stdout.write(new_data["access_token"])
                return
        except Exception:
            pass

    print("slack-mcp-token-helper: could not obtain a valid token", file=sys.stderr)
    sys.exit(1)


if __name__ == "__main__":
    main()
```

## Pattern: Claude.ai session tokens

Claude Code stores its OAuth state in `~/.claude/.credentials.json`. When running Claude Code inside a nono sandbox, broker the `accessToken` the same way — the proxy injects it into `api.anthropic.com` requests while the file is denied to the agent directly.

The helper reads from the file (which Claude Code manages as the source of truth) and refreshes via Anthropic's token endpoint, writing new tokens back so Claude Code stays in sync.

### Token helper

```python
#!/usr/bin/env python3
"""
Claude.ai OAuth token helper for nono.

Reads and refreshes tokens from ~/.claude/.credentials.json.
The file is managed by Claude Code (source of truth); this helper
reads it on the host and refreshes when needed, keeping it up to date.
"""
import json
import os
import pathlib
import sys
import time
import urllib.request

CREDS_FILE = pathlib.Path.home() / ".claude" / ".credentials.json"
TOKEN_ENDPOINT = "https://auth.anthropic.com/oauth/token"
EXPIRY_BUFFER_MS = 60_000


def load():
    if not CREDS_FILE.exists():
        print("claude-token-helper: ~/.claude/.credentials.json not found", file=sys.stderr)
        sys.exit(1)
    return json.loads(CREDS_FILE.read_text())


def save(creds):
    CREDS_FILE.write_text(json.dumps(creds, indent=2))


def do_refresh(refresh_tok):
    payload = json.dumps({"grant_type": "refresh_token", "refresh_token": refresh_tok}).encode()
    req = urllib.request.Request(
        TOKEN_ENDPOINT,
        data=payload,
        headers={"Content-Type": "application/json"},
        method="POST",
    )
    with urllib.request.urlopen(req, timeout=15) as resp:
        return json.loads(resp.read())


def main():
    now_ms = int(time.time() * 1_000)
    creds = load()
    oauth = creds.get("claudeAiOauth", {})

    access_token = oauth.get("accessToken", "")
    expires_at_ms = oauth.get("expiresAt", 0)  # already in milliseconds
    refresh_tok = oauth.get("refreshToken", "")

    if access_token and expires_at_ms > now_ms + EXPIRY_BUFFER_MS:
        sys.stdout.write(access_token)
        return

    if refresh_tok:
        try:
            body = do_refresh(refresh_tok)
            new_access = body.get("access_token")
            if new_access:
                oauth["accessToken"] = new_access
                oauth["refreshToken"] = body.get("refresh_token") or refresh_tok
                oauth["expiresAt"] = now_ms + body.get("expires_in", 3600) * 1_000
                creds["claudeAiOauth"] = oauth
                save(creds)
                sys.stdout.write(new_access)
                return
        except Exception as exc:
            print(f"claude-token-helper: refresh failed: {exc}", file=sys.stderr)

    if os.environ.get("NO_BROWSER_LOGIN") == "1":
        print("claude-token-helper: token expired and NO_BROWSER_LOGIN=1", file=sys.stderr)
        sys.exit(1)

    print("claude-token-helper: token expired — run 'claude auth login' on the host", file=sys.stderr)
    sys.exit(1)


if __name__ == "__main__":
    main()
```

## Scoping injection with endpoint_rules

Without `endpoint_rules`, a credential is injected on every request to that upstream. When an agent talks to multiple paths on the same host, or when you want to restrict which operations can use a given token, use `endpoint_rules` to narrow the scope.

```jsonc
{
  "custom_credentials": {
    "workspace_mcp": {
      "upstream": "https://mcp.workspace.example.com",
      "credential_key": "cmd://workspace_mcp",
      "env_var": "WORKSPACE_TOKEN",
      "inject_header": "Authorization",
      "credential_format": "Bearer {}",
      "endpoint_rules": [
        // Narrow to MCP protocol paths only
        { "method": "*", "path": "/mcp" },
        { "method": "*", "path": "/mcp/**" }
      ]
    }
  }
}
```

The `path` field is a glob pattern. `/**` matches any path below the prefix. `method` is an HTTP verb or `*` for any method.

A credential is only injected when the incoming request's method **and** path both match at least one rule. If no rule matches, nono returns 403 and records an audit event.

Keeping each credential's `endpoint_rules` narrow prevents cross-leaking: even if an agent constructs a request to the wrong path, the proxy will not inject that service's token.

See [Networking — Endpoint Filtering](/cli/features/networking#endpoint-filtering) for the full pattern syntax.

## Environment opt-outs

Helpers should exit non-zero when `NO_BROWSER_LOGIN=1` so headless environments (CI, containers, remote agents) fail fast rather than blocking on user input:

```python
if os.environ.get("NO_BROWSER_LOGIN") == "1":
    print("token expired and browser login disabled", file=sys.stderr)
    sys.exit(1)
```

nono treats a non-zero exit as a capture failure, surfaces a 503 to the agent, and records a `DENY CAPTURE` audit event. The agent can then return a helpful error rather than hanging.

## Testing the setup

**Verify phantom tokens are present:**

```bash
nono run --profile agent-with-mcp -- env | grep _TOKEN
# EXAMPLE_MCP_TOKEN=nono_sess_a1b2c3...
```

**Verify injection to the upstream:**

```bash
nono run --profile agent-with-mcp -- \
  curl -si http://127.0.0.1:${NONO_PROXY_PORT}/example_mcp/mcp \
  -H "Authorization: $EXAMPLE_MCP_TOKEN"
# Upstream should respond normally; Authorization header carries the real token
```

**Inspect the audit log:**

```bash
nono run --profile agent-with-mcp --audit-log /tmp/audit.jsonl -- my-agent
grep REVERSE /tmp/audit.jsonl
# {"event":"ALLOW","kind":"REVERSE","route":"example_mcp","method":"POST","path":"/mcp"}
```

Look for `ALLOW REVERSE` lines confirming injection, and `DENY CAPTURE` lines if the helper failed.

## Security notes

- **Tokens never enter the sandbox in plaintext.** The agent process only sees the phantom session token; the real access token is held by the proxy on the host side.
- **Prefer keychain over disk.** The helpers above store tokens in the system keychain (macOS Keychain, Linux Secret Service), not in world-readable files.
- **Deny raw token files.** Where mcp-remote writes to disk before migration (`~/.mcp-auth`) or where Claude Code keeps its state (`~/.claude/.credentials.json`), add a `filesystem.deny` entry so the agent cannot read them.
- **Set `cache_ttl_secs` shorter than the actual token lifetime.** This ensures the helper is re-invoked before the token expires, rather than after a failed upstream request forces a retry.
- **Scope `interaction.open_urls` tightly.** List only the exact origins the provider's OAuth flow uses; omit unrelated domains.
